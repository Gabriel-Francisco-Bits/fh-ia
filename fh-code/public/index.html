Nivel 1: Failover intra-proveedor

Si tienes múltiples cuentas/claves configuradas para el mismo proveedor (en la pestaña Claves & Conexión), rotará primero entre tus cuentas antes de cambiar a otra IA.

Nivel 2: Failover inter-proveedor

Si todas las cuentas de un proveedor fallan o agotan su cuota, conmuta automáticamente al siguiente servicio de tu lista de prioridad sin interrumpir tu trabajo.
